ADITI GAVHANE — PORTFOLIO WEBSITE

HOW TO OPEN
1. Open index.html in a modern browser. The page is built with HTML, CSS and JavaScript; no build step is required.
2. For the most reliable clipboard and local-file behavior, you can run a local server from this folder (for example, `python -m http.server 8000`) and open http://localhost:8000.

- Pastel-themed responsive portfolio with About, Skills, Projects, Certificates and Contact sections.
- Profile photo supplied by Aditi.
- Direct Resume button linking to assets/resume.pdf, opening the full PDF in a new tab for easy viewing and downloading.
- Four projects with full screenshots and descriptions: CompareX, EchoAI, EmberWatch, and Vendor Performance Analysis (Power BI Dashboard).
- Interactive screenshot gallery with full-resolution previews and arrow/keyboard navigation.
- Three original certificate PDFs linked in the Certificates section (Introduction to Prompt Engineering with GitHub Copilot, Power BI for Beginners, and Deloitte Data Analytics Job Simulation).
- Working section navigation and responsive mobile menu.
- Email Aditi button configured to open the visitor's default email composer addressed to gavhaneaditi5@gmail.com with subject "Portfolio Inquiry – Aditi Gavhane".
- Copy Email Address button with clipboard copy and fallback prompt.
